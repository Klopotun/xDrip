# VK Community Messages Exporter

Скрипт выгружает все диалоги и сообщения сообщества ВКонтакте через VK API и сохраняет их в JSON и CSV для последующего анализа AI-инструментами.

## 1. Получение токена

Для работы скрипта нужен **ключ доступа сообщества** с правами на сообщения.

### Шаг 1 — Откройте настройки сообщества

1. Зайдите в сообщество → **Управление** → **Настройки** → **Работа с API**.
2. Нажмите **Создать ключ** (или откройте существующий).

### Шаг 2 — Выберите права

Обязательно включите разрешения:

| Право | Зачем |
|---|---|
| **Сообщения сообщества** | читать и отправлять сообщения |
| **Управление сообществом** | получать список диалогов |

> Дополнительные права (фотографии, видео) нужны только если хотите загружать медиафайлы.

### Шаг 3 — Скопируйте токен

Токен выглядит как длинная строка, например:
```
vk1.a.AbCd1234...
```

Скопируйте его — он понадобится в следующем разделе.

## 2. Настройка проекта

```bash
# Клонируйте / перейдите в папку проекта
cd vk-export

# Создайте виртуальное окружение и установите зависимости
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt

# Создайте файл .env из примера
cp .env.example .env
```

Откройте `.env` и заполните:

```dotenv
VK_TOKEN=vk1.a.ВашТокенЗдесь
GROUP_ID=123456789   # числовой ID сообщества
```

**GROUP_ID** — числовая часть из URL: `vk.com/club123456789` → `123456789`.
Можно также найти: **Управление → Настройки → Информация → ID страницы**.

## 4. Результаты выгрузки

Файлы сохраняются в папку `export/` (настраивается через `EXPORT_DIR` в `.env`).

| Файл | Описание |
|---|---|
| `export/vk_conversations_raw.json` | Все диалоги со вложенными сообщениями (иерархическая структура) |
| `export/vk_messages_flat.csv` | Все сообщения в плоском виде (одна строка = одно сообщение) |

## 5. Структура данных

### JSON (`vk_conversations_raw.json`)

```json
[
  {
    "peer_id": 2000000001,
    "conversation_title": "Беседа с клиентом",
    "peer_type": "chat",
    "message_count": 42,
    "messages": [
      {
        "conversation_id": 2000000001,
        "message_id": 98765,
        "date": "2024-01-10 09:15:00 UTC",
        "date_unix": 1704877300,
        "sender_id": 111222333,
        "sender_type": "client",
        "text": "Здравствуйте, хочу узнать о заказе",
        "attachments": [
          { "type": "photo", "url": "https://..." }
        ],
        "reply_to_message_id": null,
        "conversation_title": "Беседа с клиентом"
      }
    ]
  }
]
```

### CSV (`vk_messages_flat.csv`)

| Поле | Описание |
|---|---|
| `conversation_id` | peer_id диалога |
| `conversation_title` | название диалога (для чатов) |
| `message_id` | ID сообщения |
| `date` | дата в формате `YYYY-MM-DD HH:MM:SS UTC` |
| `sender_id` | VK ID отправителя (отрицательный = сообщество) |
| `sender_type` | `client` / `community` / `manager` / `unknown` |
| `text` | текст сообщения |
| `attachments` | JSON-строка со списком вложений |
| `reply_to_message_id` | ID сообщения-цитаты (если есть) |

### Типы отправителей (`sender_type`)

| Значение | Кто отправил |
|---|---|
| `client` | пользователь VK (обычный человек) |
| `community` | само сообщество (авто-ответ, от имени группы) |
| `manager` | другое сообщество / бот |
| `unknown` | не удалось определить |

## 6. Ограничения VK API

### Ограничения по частоте запросов

VK допускает **не более 3 запросов в секунду** с одного токена.  
Скрипт по умолчанию делает паузу `0.34 с` между запросами (настраивается через `REQUEST_DELAY`).

При превышении лимита VK возвращает ошибку `#6 (Too many requests per second)` — скрипт автоматически ждёт и повторяет запрос.

### Ограничения на количество сообщений

- Метод `messages.getHistory` отдаёт максимум **200 сообщений** за запрос.
- Пагинация реализована автоматически.

### Ограничения на доступ к истории

- Некоторые старые диалоги могут быть недоступны без специального разрешения.
- Удалённые сообщения не возвращаются API.
- VK может не отдавать сообщения старше **1 года** в некоторых случаях — это ограничение платформы.

### Медиафайлы

- Скрипт сохраняет **URL** вложений, а не сами файлы.
- Ссылки на фото/видео могут быть **временными** и перестать работать через некоторое время.
- Для сохранения медиафайлов потребуется дополнительный шаг загрузки (не входит в этот скрипт).

### Права и конфиденциальность

- Токен сообщества даёт доступ **только к диалогам этого сообщества**.
- Сообщения в личных переписках пользователей недоступны.
- Не передавайте токен третьим лицам — он даёт полный доступ к сообщениям сообщества.
