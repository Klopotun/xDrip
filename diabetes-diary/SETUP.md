# Дневник диабетика — установка

## Что это

Веб-приложение на Google Apps Script + Google Sheets.
Открывается в браузере телефона, данные хранятся в вашей таблице Google.

---

## Установка (5 минут)

### Шаг 1 — Создать Google Таблицу

1. Откройте [sheets.google.com](https://sheets.google.com)
2. Создайте новую таблицу, назовите её **«Дневник диабетика»**
3. Запомните или скопируйте URL таблицы

### Шаг 2 — Создать проект Apps Script

1. В таблице: **Расширения → Apps Script**
2. Откроется редактор кода

### Шаг 3 — Скопировать файлы

**Файл `Code.gs`:**
- Удалите весь дефолтный код в редакторе
- Вставьте содержимое файла `Code.gs` из этой папки

**Файл `Index.html`:**
- Нажмите **«+»** рядом с «Файлы» → выберите **HTML**
- Назовите файл `Index` (без расширения, редактор добавит `.html`)
- Вставьте содержимое файла `Index.html`

**Манифест `appsscript.json`:**
- Нажмите шестерёнку ⚙️ → **Настройки проекта**
- Включите «Показывать файл манифеста appsscript.json»
- Замените содержимое на файл `appsscript.json`

### Шаг 4 — Развернуть как веб-приложение

1. Нажмите **«Развернуть» → «Новое развёртывание»**
2. Тип: **Веб-приложение**
3. Выполнять от имени: **Я (ваш аккаунт)**
4. Доступ: **Все пользователи, прошедшие аутентификацию Google**  
   *(или «Все» если хотите без входа)*
5. Нажмите **«Развернуть»**
6. Скопируйте URL вида `https://script.google.com/macros/s/...`

### Шаг 5 — Добавить на главный экран

**Android Chrome:**
- Откройте URL → меню ⋮ → «Добавить на главный экран»

**iPhone Safari:**
- Откройте URL → кнопка «Поделиться» → «На экран "Домой"»

## Структура данных в таблице

Листы создаются автоматически при первом использовании:

| Лист | Описание |
|------|----------|
| `Инсулин` | Все уколы: время, тип, доза, место |
| `Еда` | Приёмы пищи: ХЕ, описание, сахар до/после |
| `Сахар` | Измерения глюкозы: значение, тип |
| `Настройки` | Запомненные предпочтения |

---

## Возможности

- **Укол инсулина**: болюс / базальный / другой тип, барабанный выбор дозы,
  место укола, предупреждение при повторном использовании места,
  подсказка последней дозы для базального инсулина
- **Еда**: счётчик ХЕ с полушагом, сахар перед едой, описание
- **Сахар**: большой ввод, цветовой индикатор нормы, тип измерения
- **Журнал**: навигация по датам, статистика дня, таймлайн
- **Редактирование**: изменить любую запись, исправить время, удалить
- **Напоминание**: через 2–3 часа после еды напоминает измерить сахар
- **Время**: по умолчанию UTC+3 (Москва), можно изменить вручную
